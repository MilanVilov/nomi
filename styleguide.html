buttons

terminal text, not boxes. one primary per view.

selection

the chosen row gets ❯ and white text; the others reserve the same width with an invisible ❯. editor tabs use --mode; chips use --accent.

prompt box

full-width --rule hairlines with ❯ and a block cursor or caret.

sliders

2px track, accent fill from the default to the value, block-cursor thumb. changed rows turn the value accent.

feedback

toast (status), busy toast with braille spinner, inline action, export menu. never confirm() or alert().
